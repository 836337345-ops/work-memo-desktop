## 当前有效需求

### T101：导出分类选择修复

导出面板从空分类异步载入实际分类时，若用户尚未操作分类选择，应继续保持全部分类与“未分类”全选，导出参数 `categoryIds` 为空数组，表示不限分类。用户手动全选、反选或勾选后，分类数据变化不得覆盖其选择。

### T102：工作台名称设置

- 中间工作台顶部名称支持本机自定义，默认“工作台”，最多 30 个字符。
- 支持保存、取消和恢复默认；空名称不得保存，并显示中文提示。
- Windows 窗口标题同步规则以 T104 的最新确认口径为准。
- 应用名称保持“工作备忘录”。
- 名称只保存在本机界面设置中，不写入 SQLite、事项、备份或导出文件。

### T104：名称位置、窗口标题与导航样式调整

- Windows 窗口标题直接显示设置的工作台名称；默认名称时显示“工作台”，不添加应用名称前缀或分隔符。
- 左侧筛选栏顶部显示“{工作台名称}　修改”；“修改”位于右侧，使用更小字号的蓝色文字按钮并打开现有设置弹窗。
- 中间事项列表页顶部取消工作台名称和名称设置按钮，保留当前筛选标题、事项数量和既有操作。
- 左侧“工作日历”与“显示全部”互换现有常态底框样式，功能、文案和顺序不变。
