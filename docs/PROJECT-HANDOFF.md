# 工作备忘录项目总交接

更新日期：2026年9月13日

> 本文件只记录长期产品事实和稳定执行边界。当前版本、阶段、固定提交、任务状态和唯一下一步以 `docs/ACTIVE-VERSION.md` 为准；历史任务详情以任务卡、QA 报告和版本交接文件为准。

## 一、当前基线

- 项目目录：`D:/CODEX项目/工作备忘录`；当前分支、任务、版本和安装包状态只见 `docs/ACTIVE-VERSION.md`。
- 历史提交、测试、哈希和任务记录见对应的 `HANDOFF-版本号.md`、任务卡与 QA 报告。

## 二、产品与界面

- Windows 本地中文桌面软件，日常离线使用且无需账号；技术栈为 Tauri 2、React 19、TypeScript、Vite、Rust 和 SQLite。
- 主界面分为左侧导航、中间事项列表和按需打开的右侧编辑栏；编辑栏关闭时列表扩展宽度，编辑栏顶部操作固定，内容区独立滚动。
- 工作台名称保存在本机界面设置中，默认“工作台”，最多 30 个字符；支持保存、取消和恢复默认，空名称不得保存。
- Windows 窗口标题直接使用工作台名称；左栏顶部显示名称和蓝色小号“修改”，中间列表不重复显示名称设置。
- 窗口尺寸为 1440×920，最小 1060×700；调试版应用标识为 `com.local.workmemo.dev`。
- 应用启用单实例保护；界面为浅色简洁风格，保留浅绿色品牌色，未引入 Tailwind、Radix 或 shadcn CLI。

## 三、事项、编辑与卡片

- 事项字段包括标题、事项情况、类别、截止日期、状态、进度历史、跟进清单、备注及创建、更新、回收站时间；标题必填，类别和日期可为空。
- 状态仅有进行中、已完成、已暂停；新建默认进行中。跟进项完成不会自动改变事项状态。
- 首次打开旧数据库或恢复旧备份时，仅清除已确认属于测试数据的旧 `todo` 事项及其关联跟进和进度，其他数据不受影响。
- 从分类筛选或日历日期新建时自动带入类别或日期。右侧编辑栏可修改标题、类别、日期、事项情况、备注和跟进清单；状态与最新进度在事项卡处理。
- 编辑栏顶部固定“保存并关闭”和“取消”，已有事项另显示“删除事项”；保存成功后关闭，失败时保留输入。未保存的普通字段沿用放弃确认。
- 删除事项为软删除并进入回收站；事项卡删除使用 Tauri 原生确认框。事项卡默认收起，首行按“日期 | 类别 | 标题”单行显示，并提供状态、重要事项、修改和删除操作。
- 状态灯颜色：进行中绿色、已暂停红色、已完成橙色。点击最新进度后显示输入框；提交成功隐藏输入框且不改变卡片展开状态，失败时恢复输入。
- 卡片展开后显示事项情况、跟进清单和备注；情况与备注只读，跟进项可新增、编辑、勾选和删除。跟进修改在收起、点击外部、切换事项、删除或离开页面时自动保存一次；失败时保留草稿并阻断原动作。完成项置底，“已完成”为红色加粗。正在右侧编辑该事项时，卡片内联编辑暂时锁定。
- 重要事项使用现有黄色星标。事项卡按钮显示“设置重要事项／取消重要事项”；新建页可勾选重要事项。事项列表默认星标置顶，同组按既有时间规则排序；日历同一天内星标置前。
- 日历跳转会定位、标记并展开目标卡片，不自动打开编辑栏；不提供“一键完成”。

## 四、分类、筛选与排序

- 新数据库默认分类依次为推广、销售、拓展、包装、礼品、事务、活动、其他；既有数据库保留用户分类，不被默认值覆盖。
- 分类名称不得为空或重复，支持新增、改名和排序。删除前需确认；关联事项转为未分类，相关跟进模板同时删除。
- 启动默认显示工作日历；这是 V2.10 用户确认后对旧“默认进行中列表”规则的替换。离开日历后仍可使用“全部”、“进行中”及各筛选组；左栏工作日历按钮始终使用深绿色。
- 左栏“全部”清除搜索和全部筛选；“进行中”清除搜索并只保留进行中状态。状态、时间、分类可组合筛选。
- 状态选项为全部、进行中、已完成、已暂停；时间选项为全部、今天、本周、下周、本月、下月、历史；历史指截止日期早于本机今天。
- 分类包含全部、未分类和自定义分类。状态分组默认展开，时间和分类默认收起，展开状态保存在本机；收起时显示当前条件摘要。
- 进行中事项过期时显示“逾期”，但左栏没有独立逾期筛选。
- 搜索覆盖标题、事项情况、最新进度、跟进文字和备注，并可与筛选叠加。
- 默认按截止日期由近到远排序，无日期最后；同日按创建时间由新到旧。本周从周一开始，日期范围包含首尾当天。

## 五、跟进模板

- 模板按事项类别保存；新建页始终显示模板入口，未选择类别时入口禁用并提示“请先选择所属类别”。模板可命名，并支持新建、编辑、删除和应用。
- 应用模板会追加未完成的跟进项，忽略空项和重复文字；删除模板不影响已写入事项的跟进项。
- 编辑栏跟进区第一行左侧为“添加清单”，右侧为蓝色“模板设定/应用”。

## 六、工作日历

- 日历默认显示当前月和固定六周网格，支持上月、今天、下月和关闭。
- 日历读取全部未删除且有截止日期的事项，不继承工作台筛选；可组合使用状态和一个或多个分类筛选，包括未分类，点击“全部”清除对应限制。
- 每日最多直接显示三项，超出时显示“另有 N 项”；悬停或键盘聚焦可查看当日全部事项。
- 点击事项返回工作台并定位；“新增计划”预填日期。周末及内置节日日期显示红色。
- 内置节日包括元旦、春节、清明、劳动节、母亲节、端午、中秋和国庆。

## 七、回收站、备份与恢复

- 回收站事项只读并可还原，不提供永久清空；回收站搜索不套用正常列表筛选。
- 备份包含分类、全部事项、回收站、进度历史、跟进清单和模板。
- “一键备份到本地”写入应用数据目录下的“备份”文件夹，文件名为 `工作备份文件YYYYMMDD.json`；同日重复备份自动加序号，不覆盖旧文件。也可选择位置导出 JSON。
- 恢复前完整校验版本、时间、分类、事项、模板和关联关系；确认后先保存安全备份，再通过事务替换数据。失败保留原数据，成功显示恢复数量和安全备份路径。

## 八、TXT 导出

- 状态、时间和分类均可多选，并支持全选、反选；每组至少选择一项。接口中全选表示不限范围。
- 状态为进行中、已完成、已暂停；时间为今天、本周、下周、本月、下月、历史；分类包含全部现有分类和未分类。
- 分类异步载入时，用户尚未操作则继续全选并提交 `categoryIds=[]`；用户操作后，分类变化不得覆盖其选择。
- 只导出未删除事项。默认文件名为 `工作事项汇总YYYYMMDD.txt`，编码 UTF-8。
- 按分类顺序分组，未分类最后；组内按截止日期正序，无日期最后。一级标题使用中文序号加类别。
- 事项格式为“序号、X年X月X日，事项标题，最新进度；”，组末用句号；无日期写“未设日期”，无进度写“暂无最新进度”。

## 九、数据与安全

- 正常数据位于 Windows 当前用户应用数据目录，数据库名为 `work-memo.sqlite3`；源码和安装目录不保存正式数据。
- 测试和调试必须通过 `WORK_MEMO_DATA_DIR` 使用隔离目录，只使用虚构数据。
- 前端仅通过本地 Tauri 接口访问 SQLite，没有远程服务。时间戳使用 RFC3339，截止日期使用 `YYYY-MM-DD`。
- 保存、进度、备份和恢复失败时显示中文错误，不把失败伪装为成功。
