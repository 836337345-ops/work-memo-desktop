# V2.13 回收站、完成状态与左栏分类操作任务卡

## 一、确认、基线与分级

- 用户于 2026年9月22日确认全部需求并授权开始。
- 固定业务基线：`637ccd1474cce9ca5f05320f624a7c705ee7fc2c`（V2.12 已交付版本）。
- 分级：数据安全功能。永久删除会不可逆移除事项及关联记录，采用一个可见开发任务、PM 集成和一个独立 QA 任务。
- 当前阶段：开发准备。实际开发模型使用 Terra Medium；PM 窗口实际档位无法核实。

## 二、用户可见结果与验收标准

1. 修复从工作日历“新增计划”进入右侧新建栏后取消失效的问题。根因是预填日期让空白草稿被判定为有内容，取消按钮先在编辑器确认一次，随后页面切换公共流程再次确认，形成重复拦截。修复公共离开流程，任何新建入口取消时最多确认一次；日历预填日期仍保留。
2. 回收站每条事项提供勾选框，顶部提供全选和“永久删除所选”。全选范围是当前搜索结果；搜索条件变化后选择状态必须清晰且不得误删不可见事项。
3. 永久删除前使用 Tauri 原生确认框统一确认一次，明确不可恢复及所选数量。取消不删除；确认后在单次事务中永久删除所选事项、进度历史和跟进清单。空选择时不可执行。
4. 事项状态改为“已完成”时自动取消星标。已完成事项不显示星标，也不显示或提供重要事项按钮；改回“进行中”或“已暂停”时恢复星标入口，但不会自动恢复原星标状态。
5. 左栏移除独立“进行中”按钮；保留原“全部”入口并改名为“工作列表”，点击后仍清除搜索和筛选并显示全部未删除事项卡。
6. 左栏“状态”筛选标题改为“进度”，“全部状态”改为“全部进度”，筛选功能不变。工作日历自身的状态筛选文案不在本次改名范围内。
7. 左栏分类区域取消“设置”按钮和独立分类管理弹窗。分类标题处直接提供新增入口；每个分类直接提供改名、删除、上移、下移操作。
8. 分类新增、重名/空名校验、删除确认、删除后事项转为未分类、模板随分类删除及排序规则沿用现有契约。分类改名后，所有关联事项卡、编辑栏、日历和筛选项应立即显示新名称；事项关联关系不改变。

## 三、公共契约与数据安全

- 新增批量永久删除接口，输入为非空事项 ID 列表；后端必须验证目标均位于回收站，并在单一数据库事务中删除关联跟进、进度和事项，任一步失败全部回滚。
- 不提供“清空整个回收站”，不删除正常事项，不读取真实用户数据。
- 状态为 `done` 的事项保存时后端统一强制 `isStarred=false`，避免不同界面调用绕过规则；前端同步隐藏完成事项的星标展示和操作。
- 分类仍以稳定 ID 关联事项；改名只修改分类名称，不批量改写事项记录。
- 不新增第三方依赖，复用现有 Tauri 原生确认框、分类 API 和排序能力。

## 五、必须验证

- 日历预填日期的新建取消：空白直接取消；另有填写时只出现一次放弃确认；确认后关闭，拒绝后保留草稿。
- 回收站：单选、多选、当前搜索结果全选、取消确认、确认删除、搜索变化、空选择、部分非法/非回收站 ID、事务失败回滚。
- 永久删除后事项、跟进和进度均不存在；正常事项与未选回收站事项不受影响。
- 完成状态自动取消星标，完成事项无星标入口；切回进行中/已暂停后入口恢复但保持未星标。
- 左栏文案、工作列表行为、分类内联新增/改名/删除/排序，以及改名后的各处同步显示。
- 执行 `npm test`、`npm run build`、`cargo test --manifest-path src-tauri/Cargo.toml` 和 `git diff --check`；测试只使用隔离虚构数据。

## 七、用户调试验收反馈（2026年9月22日）

用户确认继续复用原 T131 开发和原 T132 复测，调整左栏分类操作：

1. 分类标题右侧“＋”仅用于打开新增分类对话框；取消分类列表中长期显示的新增输入框和“添加”按钮。
2. 新增分类对话框复用现有校验：名称必填、去除首尾空白、不得重名；保存成功关闭，失败保留输入并显示中文错误；取消不新增。
3. 每个分类保持单行：分类名称在左侧，“改名”“删除”文字操作放在同行最右侧；“改名”为蓝色，“删除”为红色。
4. “改名”继续在当前分类行内编辑，不新增改名对话框。
5. 取消上移、下移箭头，改为鼠标拖拽排序。使用明确拖拽把手，避免点击分类筛选或操作按钮时误拖动。
6. 拖拽过程中显示被拖分类的视觉反馈，并以明显插入线或等效占位预览最终落点；松开后调用现有分类排序接口立即持久化。
7. 拖拽取消、无位置变化或排序保存失败时不得伪装成功；失败时恢复原顺序并显示中文错误。
8. 分类新增、改名、删除、排序仍使用稳定分类 ID；关联事项及模板语义保持不变，不新增依赖。

定向验证至少覆盖：新增对话框打开/取消/成功/失败；永久新增输入框消失；同行操作文案与颜色；拖拽到上方和下方、落点预览、无变化不提交、保存失败恢复；拖拽把手以外的点击不触发排序；既有筛选、改名、删除和分类关联回归。
