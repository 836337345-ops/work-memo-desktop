## 测试边界

由于当前自动化环境不提供原生 Windows 窗口与系统文件对话框的可操作接口，真实桌面阶段只完成了安装、启动、数据库初始化、进程稳定性及卸载检查；可见界面交互和文件对话框流程由 Microsoft Edge Playwright 的界面/IPC 模拟测试覆盖，SQLite 持久化与备份保护由 Rust 测试覆盖。此限制不影响构建与安装，但首次正式使用时仍建议手动导出一次备份，确认用户选择的保存位置可写。
