## 六、交付与停止条件

- 开发员回报：正式任务 ID、工作树、分支、提交号、测试结果、遗留问题和未提交文件。
- QA 回报：固定提交、验证结果、未测范围、报告提交和工作区状态。
- 用户未完成调试验收并明确授权前，不得打包、修改 `main` 或发布。
- 发现范围扩大、公共契约变化、数据安全风险或任务环境异常时停止并报告 PM。
