# 工作备忘录 · 使用说明

这是保存在当前 Windows 用户电脑上的工作事项管理工具。首期不需要账号，日常使用不需要联网。

## 开始记录

点击“新增事项”，填写标题，按需填写工作内容、类别、截止日期和备注，点击“创建”。创建后的普通字段会自动保存，请留意“已保存”提示。若显示失败，保留当前窗口并重试。

初始类别为推广、包装、活动、拓展、方案、其他。一个事项属于一个类别；暂未选择的事项放在“未分类”。类别可自行新增、改名和调整顺序。删除类别不会删除事项，事项会转入未分类。

## 日常跟进

在“更新进度”中填写这次的进展并提交；历史记录保留原文和提交时间。未提交的文字不会进入进度历史，离开前请提交或明确放弃。

跟进清单可以逐条填写、修改和勾选完成。清单完成不自动改变事项状态，请按实际情况将事项设为“已完成”等状态。

## 找到需要处理的工作

类别、状态、日期和关键词可组合使用。日期支持今天、本周、下周、本月、下月、逾期、未设日期、自定义范围。本周从周一开始；日期筛选包含起止当天。

列表优先显示截止日期较近的事项，无截止日期排在后面。待开展或进行中的事项超过截止日期会标记逾期；已完成和已暂停不标记逾期。搜索覆盖标题、内容、最新进度、跟进文字及备注。

## 回收站与备份

删除事项后可在回收站还原，首期没有永久清空功能。

使用备份功能将全部数据导出为 JSON 文件。备份包含分类、事项、跟进清单、进度历史和回收站数据，可复制到你自己的其他存储设备保管。

恢复备份会替换软件内的现有数据。软件会先校验文件，要求确认，并在替换前自动保存一份当前数据的安全备份。恢复完成后会告知安全备份位置；恢复失败不会替换原有数据。

数据保存在 Windows 用户的应用数据目录（软件中可以查看实际位置），与安装目录分开。只在同一磁盘保存备份不能防止磁盘故障，建议定期把导出的备份另存一份。

## 首期边界

本版本只管理事项与进度，暂不提供汇总文字、AI 润色、云同步或到点提醒。后续汇总将支持按【类别】合并原文，以及类别下逐条编号两种方式。
